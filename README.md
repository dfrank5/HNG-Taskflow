# TaskFlow

A personal to-do list built with React, TypeScript, and Vite. Tasks and notes are stored in this browser's localStorage; they do not sync between devices. Use **Export** to download a JSON backup and **Import** to restore one or bring its tasks into the current list.

## Run locally

```sh
npm install
npm run dev
```

## Verify and build

```sh
npm test
npm run build
npm run preview
```

The production-ready static site is written to `dist/` and can be published using any static web host.
